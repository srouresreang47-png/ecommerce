# NovaTrend — Modern E-Commerce Web Application

A responsive e-commerce web platform developed for **MIS Year 3, Semester 1 Practice-1**, built with semantic **HTML5**, modern **CSS3** (CSS Grid, Flexbox, Glassmorphism, CSS Custom Properties), and **Vanilla JavaScript**.

---

## 🌟 Key Features & Sections

1. **Top Announcement Bar**:
   - Worldwide shipping banner, summer sale alert, and live flash deals marquee.
2. **Interactive Header & Navigation**:
   - Sticky navbar with backdrop blur and responsive mobile hamburger menu.
   - Live Shopping Bag counter badge and Wishlist badge.
   - Interactive Search Modal overlay.
   - Category dropdown navigation.
3. **Hero Section (Trending Now)**:
   - High-impact headline, subheadings, and dual Call-to-Action buttons.
   - Social proof counter with customer avatars and 5-star ratings.
   - Visual stage featuring high-fashion photography, dynamic curved backdrop, and **4 floating glassmorphic product cards** (`Air Max 270`, `Smart Watch`, `Wireless Headphones`, `Water Bottle`) with continuous floating animations.
4. **Feature Highlights Bar**:
   - 4 trust pillars: *Free Shipping ($50+)*, *Secure Payments*, *Easy Returns (30-day)*, and *24/7 Support*.
5. **Shop by Categories**:
   - 6 curated category cards: *Fashion*, *Electronics*, *Beauty*, *Fitness*, *Home Decor*, and *Accessories*.
6. **New Arrivals Product Grid**:
   - 6 products with discount / new badges, wishlist toggles, star ratings, and circular add-to-cart buttons.
   - Smooth horizontal slider navigation controls.
7. **Best Sellers Showcase**:
   - 3 detailed cards with "Bestseller" badges, star review counters, product descriptions, and "Quick Add" buttons.
8. **Promotional Banners**:
   - **Flash Sale (Up to 70% Off)**: Vibrant coral gradient banner with a **live ticking countdown timer** (Days, Hours, Minutes, Seconds) and 3D floating sneaker.
   - **Summer 2025 Collection**: Modern dark aesthetic banner highlighting fresh fitness and activewear trends.
9. **Customer Trust Guarantees**:
   - Premium Quality, Fast Delivery, Secure Checkout, and Customer Satisfaction guarantees.
10. **Interactive Slide-Out Cart Drawer**:
    - Real-time cart state with quantity adjustments (`+` / `-`), item removal, live subtotal computation, and free shipping progress tracker.
11. **Quick View Modal**:
    - Click any product to launch a detailed pop-up preview modal with quantity selectors and instant "Add to Cart" action.
12. **Toast Notification System**:
    - Floating animated status toasts confirming item additions to the cart and wishlist.

## 🚀 How to Run

### Option 1: Direct Browser
Simply double-click [`index.html`](./index.html) or open it in any modern browser (Chrome, Edge, Firefox, Safari).

### Option 2: Local HTTP Server (Python)
In this directory, run:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your web browser.

### Option 3: VS Code Live Server
Right-click [`index.html`](./index.html) and select **"Open with Live Server"**.
